# PayPay

> PayPay is Japan's largest QR/barcode mobile-payment network. Its Open Payment API (OPA v2) lets payment partners and merchants collect payments from PayPay wallet users via dynamic QR codes, web checkout, app-invoke flows, and a pre-authorize/capture flow. Auth is HMAC-SHA256; JPY settlement; transaction webhooks and daily reconciliation files.

## APIs
- [PayPay Open Payment API (OPA v2)](https://www.paypay.ne.jp/opa/doc/v1.0/dynamicqrcode): Dynamic QR, Web Payment, App Invoke, and pre-auth/capture over /v2/codes, /v2/payments, /v2/refunds.
- [Developer Portal](https://developer.paypay.ne.jp/): register a merchant/developer account and get sandbox + production API keys.
